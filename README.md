# Бот-тест «Готовы ли вы консультировать клиентов по питанию?»

Все файлы лежат в одной папке — без вложенных подпапок, чтобы было легко
загрузить на GitHub через веб-интерфейс.

## Файлы

- `main.py` — запуск бота
- `config.py` — настройки (читает `.env`)
- `handlers.py` — вся логика: /start, проверка подписки, тест, /stats
- `quiz_data.py` — текст вопросов и разборов
- `database.py` — статистика (SQLite)
- `user_state.py` — прогресс прохождения теста
- `requirements.txt` — зависимости
- `.env.example` — шаблон настроек (скопировать в `.env` на сервере)

## Как запустить на сервере

```bash
git clone ссылка-на-твой-репозиторий
cd nutribot   # или как называется папка репозитория

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
nano .env
```

В `.env` впиши:
- `BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather)
- `ADMIN_IDS` — твой Telegram ID (узнать у [@userinfobot](https://t.me/userinfobot))
- `CHANNEL_USERNAME` — уже стоит `@mya_mentoring`, менять не надо

Фото для приветствия: положи файл `start_photo.jpg` рядом с `main.py`
(то же имя, что в `.env`).

Не забудь добавить бота **администратором** канала `@mya_mentoring` —
без этого проверка подписки не заработает.

## Запуск

```bash
python main.py
```

Чтобы бот работал постоянно (не отключался при закрытии терминала),
дальше можно настроить systemd — если понадобится, просто спроси.

## Команды

- `/start` — запуск теста
- `/stats` — статистика (только для ID из `ADMIN_IDS`): сколько открыли
  бота, начали тест, закончили тест, кликнули на кнопку менторства.
